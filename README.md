# Wordle Clone 🟩

A web-based Wordle clone built with HTML, CSS, and JavaScript.

## 🎮 About
Wordle is a word guessing game where you have 6 attempts 
to guess a 5-letter word. Each guess gives you colour-coded feedback.

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 🚀 How to Play
1. Guess the 5-letter word in 6 tries
2. 🟩 Green = correct letter, correct position
3. 🟨 Yellow = correct letter, wrong position
4. ⬛ Grey = letter not in the word

## 📦 Setup
```bash
git clone https://github.com/palakkatiyar/main.git
cd main
open index.html
```
